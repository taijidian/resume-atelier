# 简历工坊 · Resume Atelier

一个无需安装、无需账号、可以离线使用的中文简历编辑器。编辑内容、切换排版、在 A4 画布上自由拖动模块，通过浏览器导出 PDF。

## 快速开始

1. 下载本仓库，使用桌面版 Chrome 或 Edge 打开 `index.html`。
2. 用自己的信息替换虚构示例，在左侧编辑、右侧预览。
3. 点击“导出 PDF”，选择“另存为 PDF”。使用 A4、100% 缩放、无边距；关闭浏览器页眉页脚，开启背景图形。

运行不需要 Python。只有修改源码后重新构建时才需要 Python 3。

## 功能

- 教育、工作、项目、论文、技能等分组，可增删、启用、排序和自定义。
- 工作经历第一行为独立的加粗总结段落，后续内容为条目列表。
- 工作和项目的职位紧跟名称，时间在右侧；窄模块允许自然换行。
- 七种预设：经典清晰、现代专业、侧标叙事、留白极简、沉稳商务、高效紧凑、学术书卷。
- 自定义排版：拖动、八向缩放、跨页移动、毫米尺寸输入、独立字号、对齐与网格吸附。
- 撤销/重做布局调整、自动整理、新增页面和干净预览。
- A4 分页预览；文字溢出和模块重叠提示。
- 浏览器本地保存、JSON 备份和导入、照片更换。
- 纯 HTML/CSS/JavaScript，无运行时外部依赖、无分析统计或远程接口。

## 使用细节

在“排版样式”中选择“自定义排版”，点击模块后拖动正文或顶部标签移动，拖动边角调整大小。方向键微调 1mm，Shift + 方向键移动 5mm；也可以在左侧输入位置、尺寸或所在页。

自定义排版保留手动位置。修改文字后，模块不会自动推开其他模块。出现红框时，放大模块、减小字号或拆分内容；可用“适应文字高度”或“自动整理”。模块相交时请检查文字是否遮挡。

“导出 PDF”调用浏览器打印窗口，不是服务器生成或自动下载。PDF 最终版式请以打印预览为准；编辑网格和拖动手柄不会打印。推荐桌面 Chrome / Edge，其他浏览器的打印结果可能不同。

## 数据与隐私

仓库仅包含虚构示例，不包含真实简历、照片或个人联系方式。姓名、手机号等数据由用户自行填写。

编辑内容保存在当前浏览器的 localStorage 中，未加密。更换浏览器、移动文件或清理浏览器数据后可能无法恢复，请定期导出 JSON 备份。备份可能包含照片和个人信息，应存放在仓库之外；不要将真实简历提交到公开仓库。

## 开发

```text
src/index.template.html     编辑界面、预设排版与分页逻辑
src/custom-layout.css       附加模板、页头与自由排版样式
src/custom-layout.js        自由画布、布局校验与交互
examples/resume.example.json 虚构示例数据
scripts/build.py            仅用 Python 标准库构建
index.html                  构建后的独立离线应用
```

```sh
python scripts/build.py
python scripts/build.py --check
```

修改 `src/` 后重新构建并同时提交 `index.html`。请检查预设切换、长文本分页、窄模块换行、拖动缩放、备份导入和 PDF 打印预览。

可通过普通静态服务器或 GitHub Pages 托管仓库根目录。托管不会自动上传用户填入的内容，数据仍保存在各自浏览器中。

## 已知限制

- 不提供 PDF / Word 简历自动解析，仅支持本工具格式的 JSON 导入。
- 自定义画布的每条经历是一个模块，过长内容需要手动拆分。
- 工作总结样式依赖“工作经历”分组名，职位同行样式依赖“工作经历”或“项目经历”分组名。
- 历史撤销仅覆盖当前会话的布局操作，不覆盖正文编辑。
- 本地保存可能受浏览器存储限制影响，尤其是包含较大照片时。
